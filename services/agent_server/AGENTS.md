# agent-server 协作约定

遵循根目录 AGENTS.md。

- `main.py`：应用工厂、启动配置、健康检查与用户密钥管理 API。
- `auth.py`：Bearer 认证、身份解析与管理员权限依赖。
- `users.py`：SQLite 用户持久化、随机密钥与 SHA-256 哈希。
- 部署必须配置 `AGENT_SERVER_ADMIN_KEY`，缺失、不足 32 字符或含空白/非 ASCII 字符时拒绝启动；数据库不可用不得跳过认证。
- 普通用户具有稳定 `user_id`，密钥重新生成或撤销时不得删除用户。每次请求重新校验，禁止缓存认证结果导致旧密钥继续可用。
- 仅创建/重置响应包含普通密钥原文，列表与错误不得返回密钥或哈希；日志禁止记录 Authorization。
- 管理接口必须使用管理员依赖；未来用户数据接口只能按认证身份读取和修改所属数据，不能信任客户端提交的用户 ID。
- 健康检查无需请求凭据；服务启动仍必须通过管理员配置和存储校验。
- 使用 uv、Ruff 与 pytest，根目录 `pnpm run check` 必须运行服务测试。测试使用临时数据库与随机凭据，不输出完整密钥。
- PydanticAI 尚未配置模型；不恢复旧插件 SDK、目录扫描、动态加载、自建工具注册或 Agent 循环。
- 当前不实现管理页面、聊天或流式协议。
